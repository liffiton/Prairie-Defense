### 🌿 What’s Built & Playable

1. **6 Native Midwestern Guardians (Towers & Units)**:
   - **🌸 Common Milkweed (*Asclepias syriaca*)**: Rapid seed darts. Upgrades add toxic cardenolides; Tier 3 unlocks **Monarch Haven**, summoning an orbiting Monarch Butterfly that buffs adjacent flowering natives by +25% attack speed!
   - **🌼 Purple Coneflower (*Echinacea purpurea*)**: Piercing herbal sniper with deep taproots that shoots through columns of pests and applies a slowing nectar.
   - **🌳 Bur Oak Mortar (*Quercus macrocarpa*)**: The savanna keystone. Lobs dense acorns with massive area-of-effect shockwaves that shatter hard-shelled armor.
   - **🦫 North American Beaver (*Castor canadensis*)**: Amphibious wetland engineer. Slaps tail creating hydraulic surge waves that knock back creeps; can be placed on land or in water!
   - **🦇 Little Brown Bat Roost (*Myotis lucifugus*)**: High-frequency echolocation aerial hunter dealing +100% bonus damage to airborne pests.
   - **🦔 Virginia Opossum (*Didelphis virginiana*)**: Scavenger immune to plant toxins that executes low-HP creeps and harvests bonus **Biomass 🍂** compost!

2. **8 Midwest Invasive Threats**:
   - **🌿 Garlic Mustard**: Secretes allelopathic root toxins suppressing nearby native plants' firing rates.
   - **🪲 Emerald Ash Borer**: Fast airborne beetle that evades 50% of ground attacks unless targeted by Bat Roosts.
   - **🪰 Spotted Lanternfly**: Erratic plant-hopper that makes sudden speed leaps.
   - **🐚 Zebra Mussel Colony**: Heavily armored mollusk cluster resistant to light darts, requiring Bur Oak acorn crushers.
   - **🌾 Japanese Knotweed**: Tough rhizome that splits into aggressive juvenile sprouts upon defeat!
   - **🐟 Asian Silver Carp**: Fast aquatic runner that leaps along water channels.
   - **🐗 Feral Hog [Boss]**: Destructive high-HP runner immune to regular slows.
   - **🌲 Buckthorn Titan [Final Boss]**: Massive suffocating thicket that regenerates health and shields trailing creeps.

3. **3 Heartland Biomes**:
   - **🌾 Tallgrass Prairie Sanctuary** (Easy): Classic winding trail through big bluestem grass and wildflowers.
   - **🌳 Oak Savanna & Glade** (Medium): Converging dual-ridge trails navigating around ancient bur oaks.
   - **🌊 Great Lakes Coastal Wetland** (Hard): Land boardwalk alongside an aquatic channel where carp and mussels swim fast!

4. **Midwest Biome Field Guide & Polish**:
   - Click the **📖 Field Guide** button to explore an illustrated in-game handbook featuring scientific names, Midwest habitats, food-web roles, and real-world backyard conservation actions (such as "Buy Where You Burn" firewood practices and planting native milkweeds).
   - **Procedural Nature Audio**: Custom Web Audio engine synthesizing seed darts, water splashes, acorn explosions, bat chirps, and prairie wind.
   - **Controls & Hotkeys**: `[1]`-`[6]` for quick guardian selection, `[U]` to upgrade, `[S]` to compost for a 70% resource refund, `[Space]` to pause or start waves, with `1x`, `2x`, `4x` speed and `Auto Next` wave toggle.

Because the entire game is a static client-side bundle (HTML5 Canvas + Web Audio, with no server-side backend required), you have several **100% free** hosting options. 

I've already updated [`vite.config.ts`](file:///home/user/dev/antigravity_tower_defense/vite.config.ts) with `base: './'` so the built assets use relative paths and will run seamlessly anywhere, and generated a standalone distribution in [`dist/`](file:///home/user/dev/antigravity_tower_defense/dist) and a zip bundle at [`prairie-defense.zip`](file:///home/user/dev/antigravity_tower_defense/prairie-defense.zip) (only 36 KB).

Here are the 3 easiest free options:

---

### Option 1: Netlify Drop *(Fastest — Live in ~30 seconds, no code or setup needed)*

This is the fastest method to get a shareable `https://something.netlify.app` link without needing Git or an account setup right away.

1. Open **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop the [`dist`](file:///home/user/dev/antigravity_tower_defense/dist) folder (located in `/home/user/dev/antigravity_tower_defense/dist`) into the upload circle on the page.
3. Netlify will instantly deploy it and give you a live URL.
4. *(Optional)* Click **Site Settings** &rarr; **Change Site Name** to customize the URL to something like `https://prairie-defense.netlify.app`.

---

### Option 2: GitHub Pages *(Best for long-term code management & automatic updates)*

If you already use GitHub, this provides a permanent `https://<your-username>.github.io/<repo-name>/` link that auto-updates whenever you push code changes.

I've already added the automated GitHub Actions workflow to [`.github/workflows/deploy.yml`](file:///home/user/dev/antigravity_tower_defense/.github/workflows/deploy.yml).

1. Initialize git and push to your GitHub repo:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Prairie Defense"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository, go to **Settings** &rarr; **Pages**.
3. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
4. The workflow will run and deploy the game in about 1 minute.

---

### Option 3: itch.io *(Best if you want a game page with player comments & discovery)*

[itch.io](https://itch.io) is free, built specifically for indie games, and allows players to play directly in their browser on desktop or mobile.

1. Create a free account on [itch.io](https://itch.io) and click **Upload New Project**.
2. Set **Classification** to **Games** and **Kind of project** to **HTML** *(You are uploading a game that will be played in the browser)*.
3. Under **Uploads**, click **Upload files** and select the pre-packaged [`prairie-defense.zip`](file:///home/user/dev/antigravity_tower_defense/prairie-defense.zip).
4. Check the box **"This file will be played in the browser"**.
5. Set viewport dimensions to **960 x 640** (the native game resolution) and check **Enable fullscreen button**.
6. Set the page to **Public** and click **Save**. You'll get a clean URL like `https://yourname.itch.io/prairie-defense`.
